Report of System Status

What the county needs before you list

Clark County requires a current Report of System Status on file before a home on septic goes on the market. It's an inspection, not a guarantee, and it has to be done by a qualified inspector.

The report records the condition of the tank, baffles, distribution box and drain field, and whether the system shows signs of failure. The tank has to be pumped to inspect it properly, which is why the inspection is done with pumping.

Questions

Inspection questions

What sellers, buyers and agents ask most.

Does every septic home sale need a Report of System Status?

In Clark County, yes. The report has to be on file with Clark County Public Health before the home is listed. Cowlitz County has its own process; call or email Northbank to ask how it applies and to book.

Does the tank have to be pumped for the inspection?

Yes. You can't see the baffles, the walls or the outlet with a full tank. That's why the inspection is done with pumping.

Who pays for the inspection?

Normally the seller, since the report has to exist before listing. Some buyers order their own inspection as well.
